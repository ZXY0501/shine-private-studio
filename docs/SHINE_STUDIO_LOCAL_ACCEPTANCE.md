# SHINE 私人工作室：本地验收版

更新时间：2026-09-10。当前代码在 `C:/Users/Lenovo/Documents/ChatGPT/SHINE`，不是旧的 Codex 工作目录。正式 GitHub Pages 和阿里云尚未发布本轮更改。

## 现在可以测试

打开本地工作台，点“收件与配色”。本轮新增内容不会删除原模板或素材；第一次从一个新端口打开，看不到旧端口的本机缓存是正常的。

1. 上传测试模板、A/B 头发。素材应保持原色；读“金色 / 银白”后才启用已确认的四层配方，肤色仍保留原样。
2. 配色手册 → 编辑金色 → 改一个颜色 → 保存新版本。已经用过旧版配色的订单应保持原结果；明确重新应用或重新读表时才用新配方。
3. 手册里的“用到当前画面”只列启用且大类匹配的组件。模板、A/B、素材 ID、版本和夹子一并用于绑定，不因同名素材混到另一单。
4. 在表单改底色，或在单层微调改线稿。前者仍可切回自动生色；后者应只覆盖这一层，不覆盖 B 或固定肤色、固定高光，也不改 PSD 的混合模式与透明度。
5. 定稿复盘 → 刷新最终改动。确认前后 HEX、原颜色词、主动修改项；选择“审美优化”并确认。仅本次客户要求不会保存到学习记录。
6. 可以不做修改，直接把自己认可的颜色加入“优质样本”。重复点击/重复导出不应增加相同证据；记录可撤回。
7. 手册 → 从当前画面保存配方。应带入实际生效颜色及图层规范，生成实验中草稿；尚未改色的原图不猜 HEX。
8. 版本与备份 → 恢复旧版本。会另存为新的版本，不抹历史。下载 JSON / Markdown、导入校验、导出复盘包都可本地完成。
9. 用 Chrome/Edge 选一个 Obsidian 专用备份文件夹。首次连接即备份当前手册，之后每次提交会尝试写入 JSON + Markdown；没选文件夹、断开或授权失效时显示待办，而不是假装已备份。部分写入失败也保留整个快照供重试；切换账户会停止旧任务，不能串用文件夹。网页的文件夹授权仍需真实浏览器确认，创建本机目录不等于已经连接。

## 账户与旧数据

订单、个人预设、灵活表单结构、手册和反馈使用账户命名空间。云端素材继续按原有共享权限工作。旧版本订单需要在“版本与备份”明确认领，认领前备份旧数据及本账户将被替换的数据；不删除原来源。

认领的是旧版本订单/预设，不会把本机未登录的新手册或反馈自动变成某个账户的知识。浏览器本机存储不是加密保险箱；同一台电脑的所有者仍可访问本机文件。
