1. 目标仍是杭州 `shine-backend`，不新建同名函数，不改原环境变量、触发器、角色和账号密钥。
2. 核对 OSS Bucket 版本控制为**从未开启**。新存储使用禁止覆盖写入保护；若为 Enabled 或 Suspended，须先调整存储实现，不能简单暂停版本控制后继续发布。
3. 核对现有 FC 角色对 `private-inbox/v1/*`、`private-handbooks/v1/*` 具备所需读写、删除及列举权限。不擅自扩大其他目录权限。
4. 核对 Bucket 私有状态、前端 origin 的 GET/PUT/HEAD 与 Content-Type 跨域配置；后端 `ALLOWED_ORIGIN` 应为实际前端 origin。
